# My Demo Developer CLI

This repository contains the source code of my personal CLI tool, built with [`quickli`](https://spmse.github.io/quickli/).

The tool itself is capable of doing the following things:

- `create` and `cd` to a directory

The tool is written in Python - due to the desire to author it using quickli.
